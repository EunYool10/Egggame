# 계란이의 모험

현대·고대·미래, 세 시대의 계란이가 엄마 품을 찾아 떠나는 선택형 텍스트 어드벤처입니다. 이야기를 하나 고르고, 상황 설명을 읽고 A·B·C 중 하나를 고르면 고른 길에 따라 엔딩에 도착합니다. 이야기 3편, 엔딩 49가지, 미니게임 6종이 있습니다.

| 이야기 | 시대 | 줄거리 | 엔딩 |
| --- | --- | --- | --- |
| 이야기 1 「냉장고 대탈출」 | 현대 | 할머니 댁 냉장고 맨 끝자리에서 들판 끝 꼬꼬엄마 품까지 | 22 |
| 이야기 2 「구지봉의 일곱째 알」 | 고대 | 하늘에서 내려온 황금알 여섯 개 사이에 끼어 버린 하얀 알이 신라 "닭의 숲"까지 | 14 |
| 이야기 3 「화성으로 간 마지막 계란」 | 미래 | 2126년 화성행 우주선의 마지막 지구산 계란이 화성 붉은 온실까지 | 13 |

## 로그인과 계정 저장

- Firebase 프로젝트 `egggame-eunyool`의 Authentication(Google)과 Firestore(`(default)`, 서울 리전 asia-northeast3)를 씁니다.
- 계정마다 `players/{uid}` 문서 하나에 엔딩별 횟수, 다녀간 장면, 플레이 기록, 이어하기(JSON), 입은 스킨을 저장합니다. 이름이나 이메일은 저장하지 않습니다.
- 처음 로그인하면 그 기기의 게스트 기록이 계정으로 옮겨집니다. 같은 계정의 기기끼리는 더 많이 진행한 쪽 기록으로 합쳐집니다.
- 보안 규칙은 `firestore.rules`에 있습니다. 본인 문서만 읽고 쓸 수 있고, 필드 구성과 엔딩·장면 이름, 스킨 id 모양, 기록 숫자, 크기를 검사합니다. 배포: `firebase deploy --only firestore:rules`
- 엔딩별 횟수 값은 규칙에서 하나하나 검사하지 않습니다(엔딩이 49개라 Firestore의 요청당 식 1000개 한도를 넘기 때문). 대신 게임이 계정 기록을 읽을 때 1~100000으로 바로잡습니다.
- 엔딩, 장면을 추가하면 `firestore.rules`의 `endingIds` · `sceneIds` 목록도 함께 고쳐야 저장됩니다. 스킨은 id 모양(영어 소문자·숫자·하이픈, 32자 이하)만 검사하므로 스킨을 더할 때는 규칙을 고치지 않아도 됩니다.
- Firebase SDK는 로그인할 때(또는 전에 로그인했던 기기에서)만 내려받습니다.

## 관리자

관리자(운영진)로 등록된 Google 계정으로 로그인하면 아래 권한이 생깁니다.

- 계란 옷장의 모든 스킨 사용
- 엔딩 도감에서 아직 못 본 엔딩까지 전부 열람 (글 읽기 포함)
- **운영진 전용 계란 103종** (운영진 계란·운영진 왕관·개발자 계란, GM·관리자·QA·도우미·이벤트 같은 명찰 10종, 배포 로켓·버그 잡이·마법사·수호천사·보석 티아라·산타·해적 선장·궤도 관제사 등): 운영진 계정에서는 계란 옷장 맨 위 '운영진 전용' 묶음에서 입을 수 있고, 일반 플레이어 옷장에서는 맨 아래 '운영진 전용' 묶음에 보이기만 합니다(입을 수 없고 옷장 개수에도 들어가지 않습니다).
- **관리자 뷰어** (타이틀의 '관리자 뷰어', 진행 중 ☰ 메뉴)

| 탭 | 할 수 있는 것 |
| --- | --- |
| 진행 상태 | 지금 모험의 온기(슬라이더), 껍질 금, 가방 아이템, 친구를 하나씩 켜고 끄기. 이야기 바로 시작 |
| 장면 지도 | 이야기별 모든 장면의 글, 조건 문단, 선택지가 어디로 가고 무엇이 바뀌는지 보기. 아무 장면으로 이동 |
| 엔딩 | 엔딩 미리 보기(도감에 기록하지 않음), 글 읽기, 엔딩 하나씩 또는 이야기 전체 기록하기·지우기 |
| 기록 | 플레이 기록 보기, 모든 엔딩·장면 기록, 도감 비우기, 기록 0으로, 이어하기 지우기, 기록 JSON 내보내기·가져오기, 계정에 바로 저장 |
| 그림 | 배경 36개, 스킨 302개(운영진 전용 103개 포함), 엔딩 그림 49개 모아 보기. 스킨 바로 입기 |
| 미니게임 | 난이도 바꾸기, 6종 연습, 이야기 속 미니게임 21개 하나씩 해 보기 |
| 옵션 | 미니게임 항상 성공, 선택지 결과 미리 보기, 장면 id 보기, 글자 바로 보이기, 일반 플레이어로 보기 |

관리자는 `js/meta.js`의 `admins`에 이메일의 해시로 등록합니다. 공개 저장소에 이메일이 그대로 드러나지 않게 하려는 것입니다. 해시는 아래 명령으로 만듭니다.

```
node -e "console.log(require('crypto').createHash('sha256').update('egggame:' + process.argv[1].toLowerCase()).digest('hex'))" 이메일주소
```

관리자 기능은 게임 화면 안에서만 동작하고, 다른 사람의 기록에는 접근할 수 없습니다.

## Render 배포

main 브랜치에 푸시하면 Render가 자동으로 다시 배포합니다. 서비스는 아래 두 방식 중 하나로 만듭니다.

**Static Site (추천)**: 무료 플랜에서도 잠들지 않아 바로 열립니다.
Render 대시보드 → New + → Blueprint → `EunYool10/Egggame` → Apply. `render.yaml` 설정이 그대로 적용됩니다.
직접 만들 때는 New + → Static Site에서 아래처럼 입력합니다.

| 설정 | 값 |
| --- | --- |
| Build Command | `mkdir -p dist && cp -r index.html css js icons img dist/` |
| Publish Directory | `dist` |

**Web Service**: 무료 플랜은 15분 동안 접속이 없으면 잠들고, 깨어나는 데 50초쯤 걸립니다.

| 설정 | 값 |
| --- | --- |
| Language | Node |
| Build Command | `npm install` |
| Start Command | `npm start` |

`server.mjs`는 의존성 없는 정적 파일 서버로, 게임 파일(`index.html`, `css/`, `js/`, `icons/`, `img/`)만 내보냅니다. 상태 확인 주소는 `/healthz`입니다.

## 게임 방법

- **이야기 고르기**: 타이틀의 '모험 시작'을 누르면 세 이야기 중 하나를 고릅니다. 이야기마다 시작 카드에서 줄거리와 목표를 알려 줍니다.
- **4장 구성**: 이야기마다 4장, 장면 8~19개. 같은 장소라도 어떤 길로 왔는지, 누구와 함께인지에 따라 글이 달라집니다.
- **온기**: 차가운 곳에서 시작합니다. 둥지까지 20℃ 넘게 데워 오고 마지막 밤(폭풍우 · 첫서리 · 모래폭풍)을 잘 버티면 진엔딩 조건을 채웁니다.
- **껍질**: 떨어지거나 부딪히면 금이 갑니다. 금이 3개가 되면 그 자리에서 그 이야기의 '와장창' 엔딩입니다.
- **가방**: 버터·쇠비늘 갑옷·수리 테이프는 금 1번을 막아 주고, 밀짚·비단·은박 담요는 추운 밤을 따뜻하게 해 줍니다. 멸치·금실은 동물의 마음을 엽니다.
- **친구**: 현대 9명, 고대 5명, 미래 4명. 한 모험에서 셋 이상 사귀면 마지막 밤에 숨은 엔딩이 열립니다.
- **미니게임 6종**: 타이밍(노란 칸에서 멈추기) · 연타(시간 안에 게이지 채우기) · 균형(◀ ▶로 버티기) · 피하기(세 줄에서 떨어지는 것 피하기) · 순서 기억(반짝인 순서대로 누르기) · 수수께끼(알맞은 답 고르기). 현대 11개, 고대 6개, 미래 4개가 있고, 설정의 난이도에 따라 칸 넓이·시간·기회가 바뀝니다.
- **엔딩 종류**: 진엔딩 3 · 히든 8 · 해피 8 · 노멀 11 · 배드 19 (현대 이야기 양계장 부화실의 「B*C치킨이 되어 버렸다!」 포함)

## 기능

- 이야기 3편(현대·고대·미래)과 엔딩 49가지, 이야기 시작 카드
- 플레이 가이드: 그림 한 장과 짧은 설명을 한 장씩 넘겨 보는 카드 5장(고르기 · 온기 · 껍질 · 미니게임 · 엔딩과 옷장). 처음 모험을 시작할 때, 타이틀의 '플레이 가이드', 진행 중 ☰ 메뉴에서 열립니다.
- 매번 다른 길: 이야기마다 중간 장면들이 구역(현대: 집 안 → 바깥 마을 / 고대: 가야 마을 → 먼 길 / 미래: 우주선 안 → 화성으로)으로 나뉘어, 모험을 시작할 때 구역마다 1~3곳을 무작위로 골라 무작위 순서로 지나갑니다. v3.7에서 이야기마다 새 장면 4곳(현대: 욕실·다락방·놀이터·동네 빵집, 고대: 가야 장터·마을 우물가·대숲·산속 동굴, 미래: 실험실·운동실·우주선 식당·의무실)이 더해져 장면은 모두 50곳입니다. 출발 장면, 구역의 앞뒤 순서, 마지막 장(엄마 둥지 → 마지막 밤)과 "트럭에 올라탄다 → 트럭"처럼 다음 장소를 콕 집는 선택은 그대로입니다. 한 모험에서 같은 장면은 다시 지나지 않습니다(이야기 파일의 route, 선택지의 to: '>').
- 매번 다른 모험: 모험마다 선택지 순서가 섞이고, 출발할 때 그날의 분위기 한 줄과 장면 사이의 '길 위의 일'(온기 ±1~2℃ 같은 작은 사건, 이야기마다 10개 남짓, js/events.js)이 무작위로 나옵니다. 같은 모험 안에서는 순서와 사건이 그대로 유지돼 이어하기·되돌리기에도 같습니다.
- 잠깐 멈춤(☰): 지금 장·온기·금·고른 선택 요약, 큰 '이어서 하기', 지난 이야기·가방과 친구·플레이 가이드·설정 4칸, 처음부터 다시·다른 이야기·타이틀로는 아래 작은 버튼
- 진행 화면: 무대 위 장 진행 표시, 이미 가 본 길에는 "가 본 길" 표시, 새 장면이 열릴 때 부드럽게 전환
- Google 로그인: 기록(엔딩 도감, 플레이 기록, 이어하기, 입은 스킨)이 계정에 저장돼 다른 기기에서도 이어집니다. 로그인하지 않아도 게스트로 그대로 플레이할 수 있습니다.
- 관리자 계정: 모든 스킨, 엔딩 도감 전체 열람, 관리자 메뉴 (위 '관리자' 참고)
- 자동 저장과 이어하기, 한 걸음 되돌리기, 지난 이야기 다시 보기
- 앱으로 설치: 타이틀 아래 '앱으로 설치'로 홈 화면에 설치할 수 있고(아이폰은 공유 → 홈 화면에 추가 안내), 한 번 열어 둔 뒤에는 인터넷 없이도 플레이할 수 있습니다 (manifest.webmanifest, sw.js, js/pwa.js).
- 새 소식: 타이틀 아래 '새 소식'에 업데이트 내역이 있고, 읽지 않은 새 버전이 있으면 NEW 표시가 붙습니다 (js/news.js, 맨 위 버전을 meta.js의 version과 맞춥니다).
- 지난 모험: 엔딩 도감 아래에 이 기기에서 최근에 끝낸 모험(최대 20번)의 지나온 길, 엔딩, 마지막 상태가 남습니다. 계정에는 올리지 않습니다.
- 설정 '읽은 글 바로 보기': 전에 본 장면의 글을 한 번에 보여 줍니다.
- 엔딩 도감: 이야기별 탭, 엔딩마다 다른 그림, 본 엔딩 다시 읽기, 잠긴 엔딩 힌트, 플레이 기록, 최단 진엔딩 기록
- 엔딩 화면: 이 이야기에서 아직 못 본 엔딩 수와 힌트 하나 보기
- 계란 옷장: 스킨 199종 (껍질 색, 무늬, 모자). 처음부터 23종이 있고, 엔딩 49개마다 계란이 하나씩 열립니다. 보상 계란은 엔딩 모으기(1~45개·전부), 엔딩 종류(진·해피·노멀·히든·배드 엔딩 n개), 이야기(시대별 엔딩 n개·전부), 탐험과 기록(가 본 장면 수, 모험 횟수, 엔딩 본 횟수, 와장창 횟수, 선택 횟수)으로 열립니다. 옷장 위 바로 가기로 묶음 사이를 오갈 수 있습니다.
- 은율이의 다른 앱 보기: 타이틀에서 상큼 과일 아케이드 존 · 논리 미궁: 대우의 열쇠 · SchoolFix를 새 탭으로 엽니다. 카드는 각 앱의 파비콘 아이콘과 색으로 꾸몄습니다.
- 설정 (화면 · 소리와 진동 · 게임으로 묶음): 글자 속도·크기, 테마, 움직임 줄이기, 효과음·배경 음악·음량, 진동, 미니게임 난이도, 데이터 초기화
- 제작 크레딧 화면, 결과 공유 (휴대폰은 공유 창, 그 밖에는 복사)
- 키보드: `A`·`B`·`C` 또는 `1`·`2`·`3`으로 선택, `Space`·`Enter`로 글 넘기기, `Esc`로 메뉴
- 소리는 모두 Web Audio로 합성하고, 계란이와 배경 그림은 코드(SVG)로 그립니다.
- 기록은 브라우저 localStorage에 저장됩니다. v1·v2에서 본 엔딩과 이어하기는 그대로 이어집니다.

## 장면 추가하기

이야기 파일(`js/stories/*.js`)의 `scenes`에 장면을 추가하고, 같은 이야기의 다른 장면 선택지 `to`에서 그 장면 이름을 가리키면 됩니다. 장면 이름과 엔딩 이름은 세 이야기를 통틀어 겹치면 안 됩니다.

```js
bakery: {
  ch: 3, place: '동네 빵집', bg: 'market', mood: 'happy', // bg는 js/art.js의 SCENES 이름
  text: [
    '상황 설명 문단 1',
    { if: 'white', text: '흰둥이와 함께일 때만 보이는 문단' }, // 조건: 아이템·친구 id, { from: '바로 전 장면' }, { flag: '표시' }, { cracked: true }
    { not: { from: 'yard' }, text: '마당에서 오지 않았을 때만 보이는 문단' },
  ],
  choices: [
    { label: 'A 선택지', to: 'yard', fx: { t: 5 }, say: '고른 직후 보여 줄 한 줄' }, // t: 온기 변화(℃), c: 금 개수 변화
    { label: 'B 선택지', to: 'field', gain: ['butter'], flag: 'bakery' }, // gain/use: meta.js의 아이템·친구 id
    {
      label: 'C 선택지', to: 'e_easter',
      alt: { need: 'anchovy', tag: '멸치를 건넬 수 있어요', use: ['anchovy'], to: 'field' }, // 조건을 채우면 결과가 바뀜
    },
  ],
},
```

미니게임은 선택지에 `game`을 붙입니다. `type`은 `timing`(기본) · `mash` · `balance` · `dodge` · `memory` · `quiz` 가운데 하나입니다.

```js
game: {
  type: 'quiz', title: '나비의 수수께끼', hint: '알맞은 답을 고르세요!', speed: 1, // speed: 빠르기·횟수 배율
  quiz: { q: '문제', options: ['답1', '답2', '답3'], answer: 0 }, // quiz일 때만. dodge는 hazard: 'rock' | 'light' | 'paw' | 'claw'
  win: { say: '성공했을 때 한 줄' },
  lose: { fx: { c: 1 }, say: '실패했을 때 한 줄' }, // to를 쓰면 실패했을 때 다른 곳으로 간다
},
```

엔딩은 `endings`에 `kind`(`true`·`happy`·`normal`·`hidden`·`bad`), `title`, `bg`, `look`(엔딩 그림), `hint`, `text`로 추가합니다. `look`은 `{ art: 'chick', shell: '#ffd34d', hat: 'party', prop: ['nest', 'sparkle'] }`처럼 쓰고, 쓸 수 있는 그림·모자·무늬·소품 이름은 `js/art.js`에 있습니다. 도감 번호는 이야기마다 `endings`에 적힌 순서대로 매겨집니다. 크레딧 이름은 `js/meta.js`의 `credits`에서 바꿀 수 있습니다.
