# 계란이의 모험

할머니 댁 냉장고 맨 끝자리, 내일 아침 계란말이가 될 차례인 계란이가 들판 너머 꼬꼬엄마 품을 찾아 떠나는 선택형 텍스트 어드벤처입니다. 상황 설명을 읽고 A·B·C 중 하나를 고르면, 고른 길에 따라 13가지 엔딩 중 하나에 도착합니다.

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

## 규칙

- **온기**: 냉장고에서 나온 계란이는 4℃에서 시작합니다. 따뜻한 곳을 지나면 올라가고, 둥지에 20℃ 이상으로 도착해야 진엔딩 조건을 채웁니다.
- **껍질**: 떨어지거나 부딪히면 금이 갑니다. 금이 3개가 되면 그 자리에서 '와장창!' 엔딩입니다.
- **엔딩 도감**: 한 번 본 엔딩은 브라우저(localStorage)에 기록됩니다.
- 키보드 `A`·`B`·`C` 또는 `1`·`2`·`3`으로 고를 수 있고, '한 걸음 되돌리기'로 직전 선택을 취소할 수 있습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `story.js` | 장면, 선택지, 엔딩 데이터. 이야기를 고치거나 늘릴 때는 이 파일만 수정하면 됩니다. |
| `game.js` | 진행 엔진 (글자 출력, 선택 처리, 온기·껍질 계산, 엔딩 도감) |
| `style.css` | 화면 디자인 (라이트/다크 테마) |

## 장면 추가하기

`story.js`의 `scenes`에 장면을 추가하고, 다른 장면의 선택지 `to`에서 그 장면 이름을 가리키면 됩니다.

```js
bakery: {
  ch: 2, place: '동네 빵집', mood: 'happy',   // mood: calm, happy, worried, scared, brave, sleepy
  text: ['상황 설명 문단 1', '상황 설명 문단 2'],
  choices: [
    { label: 'A 선택지', to: 'yard', fx: { t: 5 }, say: '고른 직후 보여 줄 한 줄' },
    { label: 'B 선택지', to: 'e_easter' },
    { label: 'C 선택지', to: 'field', fx: { c: 1 } },   // t: 온기 변화(℃), c: 금 개수 변화
  ],
},
```

엔딩은 `endings`에 `kind`(`true`·`happy`·`normal`·`hidden`·`bad`), `title`, `text`로 추가합니다. 도감 번호는 `endings`에 적힌 순서대로 매겨집니다.
