# 계란이의 모험

할머니 댁 냉장고 맨 끝자리, 내일 아침 계란말이가 될 차례인 계란이가 들판 너머 꼬꼬엄마 품을 찾아 떠나는 선택형 텍스트 어드벤처입니다. 상황 설명을 읽고 A·B·C 중 하나를 고르면, 고른 길에 따라 15가지 엔딩 중 하나에 도착합니다.

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

## 게임 방법

- **4장 구성**: 냉장고 → 할머니 집 → 바깥 세상 → 들판. 장면 15개, 엔딩 15개 (진엔딩 1 · 해피 3 · 노멀 3 · 히든 2 · 배드 6)
- **온기**: 4℃에서 시작합니다. 둥지까지 20℃ 넘게 데워 오고 폭풍우 치는 밤을 잘 버티면 진엔딩 조건을 채웁니다.
- **껍질**: 떨어지거나 부딪히면 금이 갑니다. 금이 3개가 되면 그 자리에서 '와장창!' 엔딩입니다.
- **가방**: 버터(금 1번 막기), 멸치, 허수아비의 밀짚. 아이템을 가지고 있으면 어떤 선택지의 결과가 바뀝니다.
- **친구**: 노른자 할아버지, 흰둥이, 나비, 백구, 허수아비, 족제비. 셋 이상 사귀면 숨은 엔딩이 열립니다.
- **미니게임**: 뛰어내리기, 썰매, 담벼락, 징검다리에서 왔다 갔다 하는 계란이를 노란 칸에서 멈추세요.

## 기능

- 자동 저장과 이어하기, 한 걸음 되돌리기, 지난 이야기 다시 보기
- 엔딩 도감 (잠긴 엔딩 힌트, 플레이 기록, 최단 진엔딩 기록)
- 계란 옷장: 엔딩을 볼수록 해금되는 스킨 15종 (껍질 색, 무늬, 모자)
- 설정: 글자 속도·크기, 테마, 효과음·배경 음악·음량, 진동, 미니게임 난이도, 움직임 줄이기, 데이터 초기화
- 제작 크레딧 화면, 결과 복사
- 키보드: `A`·`B`·`C` 또는 `1`·`2`·`3`으로 선택, `Space`·`Enter`로 글 넘기기, `Esc`로 메뉴
- 소리는 모두 Web Audio로 합성하고, 그림은 모두 코드(SVG)로 그려서 외부 파일이 없습니다.
- 기록은 브라우저 localStorage에 저장됩니다. v1에서 본 엔딩은 도감으로 이어집니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `js/story.js` | 장면, 선택지, 엔딩 데이터. 이야기를 고치거나 늘릴 때는 주로 이 파일을 수정합니다. |
| `js/meta.js` | 아이템, 친구, 계란 스킨, 제작 크레딧 |
| `js/art.js` | 계란이·병아리·모자·장소 배경 그림 (SVG) |
| `js/core.js` | 저장(설정, 이어하기, 도감), 효과음과 배경 음악, 진동 |
| `js/ui.js` | 화면 전환, 창과 알림, 타이틀, 도감, 옷장, 설정, 크레딧 |
| `js/game.js` | 진행 엔진 (선택 처리, 미니게임, 엔딩, 입력) |
| `css/base.css`, `css/game.css` | 화면 디자인 (라이트/다크 테마) |

## 장면 추가하기

`js/story.js`의 `scenes`에 장면을 추가하고, 다른 장면의 선택지 `to`에서 그 장면 이름을 가리키면 됩니다.

```js
bakery: {
  ch: 3, place: '동네 빵집', bg: 'market', mood: 'happy', // bg: fridge, kitchen, room, basket, market, yard, alley, stream, field, storm
  text: ['상황 설명 문단 1', '상황 설명 문단 2'],
  choices: [
    { label: 'A 선택지', to: 'yard', fx: { t: 5 }, say: '고른 직후 보여 줄 한 줄' }, // t: 온기 변화(℃), c: 금 개수 변화
    { label: 'B 선택지', to: 'field', gain: ['butter'] }, // gain/use: meta.js의 아이템·친구 id
    {
      label: 'C 선택지', to: 'e_easter',
      alt: { need: 'anchovy', tag: '멸치를 건넬 수 있어요', use: ['anchovy'], to: 'field' }, // 조건을 채우면 결과가 바뀜
    },
  ],
},
```

엔딩은 `endings`에 `kind`(`true`·`happy`·`normal`·`hidden`·`bad`), `title`, `art`, `hint`, `text`로 추가합니다. 도감 번호는 `endings`에 적힌 순서대로 매겨집니다. 크레딧 이름은 `js/meta.js`의 `credits`에서 바꿀 수 있습니다.
